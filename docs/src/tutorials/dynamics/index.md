# Part 3 — Dynamics

[← All Tutorials](../index.md)

Everything so far was static. This Part introduces the operator half of the
machinery (MPOs), makes the state move via Trotter–Suzuki gates and TEBD,
points that engine at a real quantum quench, and probes the area law from
both sides — ballistic entanglement growth after a quench versus the bounded
entanglement of a ground state found by imaginary-time evolution.
